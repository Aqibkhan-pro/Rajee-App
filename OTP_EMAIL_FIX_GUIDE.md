# OTP Email Spam Issue - Backend Fix Guide

## Problem
OTP emails from `https://rajeeac-63le.vercel.app/send-otp` are being marked as spam because they lack proper branding and authentication.

**Current Email Issue:**
- Subject: Generic or missing "Rajee" branding
- Body: Generic message without company identification
- Sender: Generic sendgrid.net address (untrusted)
- Missing DKIM/SPF authentication

## Solution: Update Backend Email Template

The backend API endpoint needs to send emails with proper Rajee branding. Here's what needs to be updated:

### 1. Email Subject Line
**Change from:**
```
(generic OTP code)
```

**Change to:**
```
Your Rajee OTP Code - 6 Digit Verification Code
```

### 2. Email Body
**Change from:**
```
Your OTP is 265388. It expires in 10 minutes.
```

**Change to:**
```
Welcome to Rajee!

Your Rajee verification code is: 265388

This code expires in 10 minutes.

If you didn't request this code, please ignore this email or contact our support team.

---
Rajee App
support@rajee.com
```

### 3. Sender Email Configuration
**Update in SendGrid/Email Provider:**
- **From Name:** "Rajee" or "Rajee Verification"
- **From Email:** Use a verified domain email like:
  - `noreply@rajee.com`
  - `verify@rajee.com`
  - `otp@rajee.com`

### 4. SendGrid Account Setup (if using SendGrid)

1. **Verify Sender Domain:**
   - Go to SendGrid Dashboard → Settings → Sender Authentication
   - Add and verify your domain (rajee.com)
   - Complete DKIM and SPF authentication

2. **Create Verified Sender:**
   - Marketing → Senders
   - Add sender with verified domain
   - Use `otp@rajee.com` or similar

3. **Enable Authentication:**
   - Enable DKIM signing
   - Enable SPF records
   - Add DMARC policy

### 5. Backend Email Template Example (Node.js/SendGrid)

```javascript
const sgMail = require('@sendgrid/mail');
sgMail.setApiKey(process.env.SENDGRID_API_KEY);

async function sendOTP(email, otp) {
  const msg = {
    to: email,
    from: 'otp@rajee.com', // Verified sender
    subject: 'Your Rajee OTP Code - Verify Your Email',
    html: `
      <div style="font-family: Arial, sans-serif; line-height: 1.6; color: #333;">
        <h2 style="color: #2979C8;">Welcome to Rajee!</h2>
        
        <p>Your Rajee verification code is:</p>
        
        <div style="background-color: #f4f5f9; padding: 20px; text-align: center; border-radius: 8px; margin: 20px 0;">
          <h1 style="color: #2979C8; letter-spacing: 5px; margin: 0;">${otp}</h1>
        </div>
        
        <p><strong>This code expires in 10 minutes.</strong></p>
        
        <p>If you didn't request this code, please ignore this email or <a href="https://rajee.com/support">contact our support team</a>.</p>
        
        <hr style="border: none; border-top: 1px solid #ddd; margin: 20px 0;">
        
        <footer style="font-size: 12px; color: #999;">
          <p>Rajee App | <a href="https://rajee.com">www.rajee.com</a></p>
          <p>This is an automated message, please do not reply to this email.</p>
        </footer>
      </div>
    `,
    text: `Your Rajee verification code is: ${otp}\n\nThis code expires in 10 minutes.`
  };

  try {
    await sgMail.send(msg);
    return { success: true, message: 'OTP sent successfully' };
  } catch (error) {
    console.error('SendGrid error:', error);
    throw error;
  }
}
```

### 8. Email Authentication Records

Add these DNS records to your domain:

**SPF Record:**
```
v=spf1 include:sendgrid.net ~all
```

**DKIM Record:** (Generated by SendGrid)
```
[From SendGrid dashboard]
```

**DMARC Record (Optional but recommended):**
```
v=DMARC1; p=quarantine; rua=mailto:admin@rajee.com
```
